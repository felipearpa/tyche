# Tasks

No backend or persistence tasks are required; both apps reuse the existing current-pool score endpoint. Follow the [design](design.md) and [bet-history scenarios](specs/bet-history/spec.md), using the [saved reference](reference/history-reference.png) for visual comparison.

Before authoring any new test code, complete the repository-required ARTEMIS exploration on an authorized Android device, including `adb devices -l` and user device selection when ambiguous, and record verified interactions. Verify iOS-specific behavior on the simulator as well. Reuse those observations across the platform groups; authored UI tests must use verified locators/interactions and explicit waits. Planning this change does not count as device exploration.
